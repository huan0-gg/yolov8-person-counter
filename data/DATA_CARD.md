# 数据集说明（Data Card）· v2.0

> 本文档说明项目训练与验证所用数据的**来源、构成、标注方式、用途边界**，
> 保证每个数字都能追溯到数据来源与生成过程，不虚构、不夸大。

## 1. 一句话概要

可复现的教室人员检测数据集：**84 张训练集 + 22 张验证集，801 个 person 边界框**，
由项目已有真实图片经"透视合成 + 精确放置标注"生成，固定 seed=42 可一键重建。

## 2. 数据来源

| 组成 | 源文件 | 来源说明 | 用途 |
|---|---|---|---|
| 背景底图 | `assets/classroom_empty.jpg` | 真实空教室照片（项目 Web 界面截图裁剪，含课桌与黑板） | 合成样本背景 |
| 人物实例 | `assets/demo.jpg` | **ultralytics 官方 COCO bus.jpg 样例**（真实街景人物，COCO 数据集） | 裁剪 4 个 person 实例用于合成 |
| 真实域对照 | `assets/demo.jpg`、`assets/classroom_crowded.jpg` | 上述 COCO 样例 + 真实密集教室截图 | 原图/翻转/亮度变体，防止模型只认合成图 |

**合规说明**：所有源图来自项目已有的公开样例与自采截图，仅用于课程项目演示；
未使用任何受限或隐私数据。合成图中人物来自公开 COCO 样例，不涉及真实学生身份。

## 3. 生成流程（`scripts/build_dataset.py`）

1. **提取人物实例**：用 COCO 预训练权重 `yolo26n.pt` 检测 `demo.jpg` 的 person 类
   （conf≥0.30），裁剪得到 4 个真实人物实例，过滤掉宽高比异常的遮挡残片。
2. **合成教室场景**：把人物实例按 4 列梯形网格（上窄下宽，贴合透视）粘贴到空教室底图，
   每张图随机放置 4–12 人，附轻微水平翻转与亮度扰动。
3. **精确标注**：边界框由**放置坐标直接计算**得到（非模型猜测），因此合成样本的
   标签位置是准确的——这是本数据集能支撑训练验证的关键。
4. **真实域对照**：并入 2 张真实图片各自的原图/翻转/亮度变体，用同一权重伪标注。
5. **划分**：固定 seed=42 打乱后按 8:2 分为 train / val。

一键复现命令：

```bash
python scripts/build_dataset.py --seed 42 --total 100
```

## 5. 用途与边界（重要）

**可用于**：
- 演示完整训练流程（数据 → 训练 → 验证 → 导出 → 对比）；
- 在同一数据上做 A/B 单变量实验（增强策略、推理参数、座位判定）；
- 教学展示"数据如何影响模型表现"。

**不可用于**：
- 作为真实课堂密集人群检测精度的权威结论——合成数据的人物姿态、遮挡分布
  与真实课堂不同，mAP 数值仅表示"在本数据集上的表现"；
- 生产部署或安全相关决策。

**若要得到真实场景精度**：按 README 的方案 B 自采 300–500 张课堂照片并人工精标，
替换 `data/images`、`data/labels` 后重跑训练与评估即可。

## 6. 与 1.0 的区别

1.0 版本没有实际数据集，mAP 只能记为 0 并注明"待测"；
2.0 通过本数据卡所述方法补齐了可训练、可验证、可复现的数据，
使训练脚本、模型输出与结果验证都能真实跑通并留下可复核证据。
