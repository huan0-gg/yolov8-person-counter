# 项目宣传视频 · 制作说明与分镜

> 对应课程要求：**用 rea-video 拆解参考片 → 用 OpenMotion 生成可编辑视频**
> 本目录交付的是**可编辑的生成工程 + 成片 + 分镜脚本**，而不是一段无法修改的录屏。

---

## 一、交付物

| 文件 | 说明 | 用途 |
|---|---|---|
| `promo_45s.mp4` | 45 秒 / 1280×720 / 30fps / H.264 | 课堂路演、LinkedIn、答辩开场 |
| `cover.gif` | 4.2 秒 / 640×360 / 50 帧 / 约 0.1 MB | README 顶部封面动图 |
| `ui.png` | Gradio 界面真实截图 | README「能看」入口 |
| `evidence/summary.json` | 视频中所有数字与检测框的原始来源 | 溯源与复核 |
| `../scripts/make_promo.py` | **可编辑工程**：改文案 / 改配色 / 改时长都在这里 | 多版本重制 |
| `../scripts/collect_promo_assets.py` | 重新跑一遍推理，刷新证据帧 | 数据更新后重制 |

**可编辑性**：`make_promo.py` 用「场景类 + 时间轴」组织，每个镜头是一个 `class S*`，改 `dur` 改时长，改 `ITEMS` / 文本常量改文案，改顶部 `ACC / WARN / BG` 改品牌色。重跑一条命令即可出新片，不需要重新剪辑。

**节奏设计**：3.4s 一个信息块起步，Demo 段拉到 8s 给足观看时间，指标段 6.4s 配柱状图增长动画，结尾 4.2s 留白收口。全片 9 个镜头、7 次转场，均为「淡入 + 位移 8–22px」，不使用花哨转场，避免抢内容。

**转场与动效**：
- 元素统一 `ease-out cubic` 入场，位移不超过 26px；
- 检测框按 x 轴顺序逐个描边出现（0.05s 间隔），模拟"正在识别"；
- 座位网格按行列逐格缩放出现，而不是整体闪现；
- 数字用插值滚动，不做跳变。

> **口径提醒（重要）**：README 与答辩 PPT 里写的是「13 → 23」。其中 **13 来自最初那张旧版截图**，
> 用当前权重复现不出来；同权重、同图、只改推理参数，现在可复现的是 **9 → 23**。
> 本视频采用可复现的 9 → 23。对外表述建议统一为「9 → 23」，或注明「13 为旧版本截图状态」。
>
> 复现这组对照：`python scripts/probe_counts.py`（会打印 权重 × 参数 四种组合的真实人数）。

**画面即证据**：视频里的检测框坐标不是画上去的，是从 `summary.json` 读出来再渲染的；
换一张图重跑 `collect_promo_assets.py` + `make_promo.py`，整片自动更新。

## 四、参考片拆解（rea-video 环节）

课程要求「先拆解优秀案例，再生成自己的视频」。**目前没有拿到你选定的参考片文件**，因此这一步只完成了结构性拆解（依据课程给出的 45 秒模板），没有做逐镜头拉片。

已完成的「可复用表达方式」提炼：

| 维度 | 参考做法（同类技术产品短片通用） | 本片落地 |
|---|---|---|
| 开场 3 秒 | 抛问题，不报名字 | 「还在靠点名？」先给痛点 |
| 节奏 | 3–4 秒一个信息块 | 9 个镜头，最长 8 秒（Demo） |
| 镜头语言 | 结果优先于过程 | Demo 段占 13.4s，占比 30% |
| 字幕 | 一行一个结论，数字前置 | 「23 人」「+22.3%」单独放大 |
| 转场 | 只用位移与淡入 | 全片无 3D 翻转 / 无音效堆叠 |
| 收尾 | 明确下一步动作 | GitHub 地址 + 一条命令 |

**要把这一节补成真正的拉片报告，需要你提供**：参考视频文件（或链接）、你希望借鉴的 1–2 个点（例如"它的数据段怎么讲"）。拿到后我可以按「镜头号 / 时长 / 景别 / 字幕 / 转场 / 可复用点」逐条输出，再回填到本表。

## 五、重制与改版指引

```bash
# 1) 数据有更新时，先刷新证据帧（会真实跑一遍推理，约 30s）
python scripts/collect_promo_assets.py

# 2) 重新合成视频与封面（约 4 分钟，CPU）
python scripts/make_promo.py
```

常见改法：

| 想改什么 | 改哪里 |
|---|---|
| 时长（15s / 90s） | 各 `class S*` 的 `dur`，并同步顶部 `DUR`（有断言校验总时长） |
| 文案 | 各场景 `ITEMS` / `draw()` 里的字符串 |
| 品牌色 | 顶部 `ACC`（主色）/ `WARN`（强调）/ `BG`（底色） |
| 换成真实录屏 | 把 `S4` / `S5` 的静态图替换为视频抽帧序列，或将 `RAW_*` 换成录屏首帧 |
| 加配音 / BGM | 在 `encode_mp4()` 的 ffmpeg 命令加 `-i bgm.mp3 -c:a aac -shortest` |

> 目前成片是**无声版**。仓库内不放版权不明的音乐；若课程要求配音，建议用自己录的讲解音轨，
> 按分镜表逐段对齐即可（每段时长已在表中给出）。
