# 指定区域（ROI）标注使用说明

v2.2 新增：在**不训练、不换权重**的前提下，让检测结果明确标出"要管的范围"，
并给出区域内 / 区域外的人数。典型用途：

- 教室只统计**座位区**，不算走廊路过的人；
- 会议室只统计**会议桌周边**，不算玻璃墙外走动的人；
- 考场只统计**考生区**，把监考老师（站在区域外）排除在到岗人数之外；
- 多机位/多分区时，一张图里画多个区域，分别出人数。

## 1. 配置怎么写

打开 `configs/config.yaml`：

```yaml
regions:
  enabled: true
  min_inside_ratio: 0.60     # 框内面积被区域覆盖多少才算"区域内"
  filter_outside: false      # true = 直接丢弃区域外检测（区域模式）
  items:
    - name: seat_zone        # 英文标识，接口里用它取数
      label: 监测区域         # 图上显示的中文名
      points:                # 多边形：按顺序给顶点即可，自动闭合
        - [0.07, 0.42]
        - [0.93, 0.42]
        - [0.99, 0.99]
        - [0.01, 0.99]
      color: [170, 212, 45]  # BGR 颜色
      count: true            # 是否在标签上显示人数
```

矩形更省事，四个数就够：

```yaml
    - name: podium
      label: 讲台区
      rect: [0.34, 0.10, 0.66, 0.38]   # x1, y1, x2, y2
      color: [60, 190, 250]
```

**坐标一律是 0~1 的归一化值**（相对图片宽高），换分辨率、换机位都不用改代码。
写成像素值会直接抛错，避免"看着像生效了其实全错位"。

字段含义：

| 字段 | 作用 | 默认 |
|---|---|---|
| `min_inside_ratio` | 框内面积被区域覆盖到该比例，才算落在区域内 | 0.60 |
| `filter_outside` | 开启后区域外检测直接丢弃（区域模式） | false |
| `count` | 标签上是否带人数 | true |
| `color` | 描边/填充/标签底色（BGR） | 自动配色 |

## 2. 图上会画成什么样

- 区域用 **2px 高对比描边 + 10% 半透明填充 + 四个角点方块**勾出来；
- 左上角贴一个**带底色的标签条**，直接写区域名和区域内人数，例如 `考勤区 A（左半区） 12 人`；
- 区域内的人员框是**黄色实线**，区域外的是**灰色细线**并带 `OUT` 后缀；
- 右上角面板多两行：`Inside ROI: 12  Outside: 9`。

## 3. 怎么把区域标定准

1. 截一张该机位的画面，量出区域四角的像素坐标 `(px, py)`；
2. 除以图片宽高得到归一化值：`x = px / width`，`y = py / height`；
3. 先把结果贴进 `regions.items[0].points`，用下面的命令**只渲染区域**确认：

```bash
python scripts/preview_region.py --image assets/ai/classroom_seat.jpg \
    --poly "0.01,0.30 0.99,0.27 0.99,0.99 0.01,1.00" \
    --out docs/region/_preview.jpg
```

4. 对上了再跑完整检测。

## 4. 两种工作模式

| 模式 | 配置 | 适用 | 实测（22 张验证集 / 179 个标注） |
|---|---|---|---|
| 通用模式 | `filter_outside: false`（默认） | 需要"画面里所有人"的总数 | Precision 0.8788、Recall 0.8101、误检 20、漏检 34 |
| 区域模式 | `filter_outside: true` | 只统计指定区域（考勤/占用率） | Precision 0.9329、Recall 0.7765、误检 10、漏检 40 |

区域模式把区域外的框直接丢掉，所以误检从 20 降到 10；代价是"半个身子在区域外"的人
可能被判为区域外，需要调低 `min_inside_ratio`（比如 0.4）来放宽。

两份数据的完整来源与复现命令见 [`docs/EVAL_v2.2.md`](EVAL_v2.2.md)。

## 5. 常见问题

**区域画了但不显示？**
检查 `regions.enabled` 与 `display.show_regions` 是否都为 `true`；Web 界面上
"标注指定区域"的勾选框也要勾上。

**所有人都被判成区域外？**
多半是坐标写成了像素值，或者多边形顶点顺序自交。用 `scripts/preview_region.py`
先单独看区域形状最快。

**多个区域怎么统计？**
`items` 下继续加元素即可，每个区域独立出人数；一个框只会归属覆盖它面积最大的那个区域，
不会重复计数。接口里读 `result["regions"]`（含每个区域的 `count`）与
`result["outside_persons"]`。

**会影响座位占用判定吗？**
不会。座位网格（`seat_grid`）和区域（`regions`）是两套独立几何：前者决定"哪个座位被占"，
后者决定"这个人在不在管辖范围"。两者可以同时开。
